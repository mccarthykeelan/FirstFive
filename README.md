# FirstFive

> A beginner-friendly walk/run coach that helps new runners build toward their first 5K.

FirstFive is a JavaScript learning project inspired by the **Couch to 5K** app available on the iOS App Store and Google Play. It will begin as a browser-based experience, then grow into an offline-first Progressive Web App (PWA) that feels at home on Android and iOS.

> **Project status:** Early development - the foundation and development tooling are being set up.

## Why FirstFive?

Starting to run can feel intimidating. FirstFive aims to make the first steps simple: clear timed walk/run intervals, an easy-to-follow weekly plan, and visible progress without unnecessary complexity.

## Planned features

- Structured beginner walk/run workouts
- A focused interval timer with clear cues
- Week and workout progress tracking
- Responsive design for phones, tablets, and desktop
- Offline support through PWA technology
- Local-first data storage, with no account required initially

## Tech

- HTML, CSS, and vanilla JavaScript
- [Vite](https://vite.dev/) for local development and production builds
- Progressive Web App features planned for a later milestone

## Getting started

```bash
git clone https://github.com/mccarthykeelan/FirstFive.git
cd FirstFive
npm install
```
